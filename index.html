Frequently Asked Questions

Everything you need to know about OmniTools 2.0 privacy, offline PWA capabilities, and supported formats.

How does OmniTools 2.0 guarantee 100% client-side privacy and zero server uploads?
Every PDF conversion, image compression, financial calculation, and developer utility on OmniTools executes strictly inside your browser's local memory using HTML5 Web APIs (Canvas, FileReader, Blob, Web Crypto) and client-side libraries. Your files never touch an external server.
Can I use OmniTools offline as a Progressive Web App (PWA)?
Yes. OmniTools 2.0 includes a Web App Manifest and Service Worker that cache static assets and tool interfaces so you can install it on desktop or mobile and run offline-capable utilities without an active internet connection.
What file formats are supported across the PDF and image tools?
OmniTools supports bidirectional conversions across PDF, DOC/Word, XLSX/Excel, CSV, HTML, TXT, JSON, XML, ZIP, PNG, JPG/JPEG, and WebP, along with lossless/lossy resizing, 100KB target compression, merging, splitting, and watermarking.
Are all 64 tools completely free with no account or paywalls?
Yes. All 64 utilities are 100% free with zero ads, zero registration walls, and no arbitrary daily file limits—bounded only by your browser's available device memory.
Which browsers are supported by OmniTools 2.0?
OmniTools supports all modern evergreen browsers including Google Chrome, Microsoft Edge, Mozilla Firefox, and Apple Safari on desktop and mobile devices.
How do bookmarks, recent tools, and Ctrl+K command search work?
Press Ctrl+K (or Cmd+K on macOS, or /) from any page to open the instant command palette. You can also star any tool to pin it to your Quick Access bar; favorites and recent history are stored privately in your browser's localStorage.
